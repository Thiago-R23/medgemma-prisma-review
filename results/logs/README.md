# Registros do processo

Esta pasta contém os registros operacionais da revisão sistemática.

Os arquivos documentam as etapas de busca, triagem e tomada de decisão, permitindo acompanhar a evolução do processo e reproduzir as decisões metodológicas.

## Arquivos

### `search_log.md`

Registra as buscas realizadas nas bases de dados, incluindo estratégias, períodos e quantidade de registros recuperados.

### `screening_log.md`

Registra a evolução quantitativa das etapas de triagem.

### `decision_log.md`

Registra decisões relevantes de inclusão e exclusão, especialmente durante a avaliação dos textos completos.

## Princípio de rastreabilidade

As informações registradas nesta pasta devem permitir relacionar:

**estratégia de busca → registro recuperado → deduplicação → triagem → avaliação do texto completo → decisão final.**
