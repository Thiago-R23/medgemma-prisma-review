# Triagem dos estudos

Esta pasta contém os arquivos utilizados para documentar o processo de triagem e seleção dos estudos identificados nas bases de dados.

## Fluxo de seleção

O processo segue a seguinte sequência:

```text
Registros identificados
        ↓
Remoção de duplicatas
        ↓
Triagem por título e resumo
        ↓
Avaliação do texto completo
        ↓
Estudos incluídos
```
